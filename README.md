# Лев и Яша — сервис проката детских игрушек и товаров

Сайт-витрина для проверки идеи проката детских товаров.

## Стек
- HTML5, CSS3, ванильный JavaScript
- Без сборщиков и фреймворков
- Хостинг: Vercel
- Данные: статический JSON (на этапе MVP)

## Структура
- `index.html` — главная
- `catalog.html` — каталог
- `product.html` — карточка товара
- `cart.html` — корзина
- `checkout.html` — оформление аренды
- `css/` — стили (токены, база, компоненты, layout, страницы)
- `js/` — скрипты
- `data/products.json` — данные товаров
- `assets/` — изображения, иконки, шрифты

## Локальный запуск
Открой `index.html` в браузере или запусти простой сервер:
